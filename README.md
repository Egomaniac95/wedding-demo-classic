# Invitación de boda clásica

[Ver la demostración](https://egomaniac95.github.io/wedding-demo-classic/)

Muestra comercial de diseño de invitaciones digitales. Las personas, la historia y las cuentas son ficticias. La música instrumental fue creada para la demo. El local de ejemplo es un establecimiento real conservado con autorización del propietario del proyecto.

Este repositorio contiene únicamente la versión estática publicada. Los proyectos editables y su historial de trabajo se conservan en repositorios privados. La clave **GIFT** abre los detalles de muestra; no constituye autenticación. La demo no procesa pagos ni envía confirmaciones reales.
